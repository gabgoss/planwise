# Reference Library

**Purpose:** Find the reference that governs the work in front of you. Each row names a reference family and the situation that calls for it. A family split into `-Part-N-` files has one row: the base file first, then each Part. Read the file itself before acting on a topic it covers.

This file is generated. Each row comes from the `consult-when:` frontmatter key of every file in the family: the base file's value first (or the lowest Part's when the family has no base file), then each later Part's value, introduced by that Part's link. To change a row, edit that key in the reference and regenerate with the plugin repository's `tools/gen_reference_library.py`.
